BINLY - CLEAR ALL FEATURE IMPLEMENTATION REPORT
================================================

Date: 2026-08-14

We have implemented a "Clear All" button with an immediate UI clear and an 8-second "Undo" toast notification, restricted to the owner of the bin. If the undo action is not clicked within the duration, the cleared state is auto-saved/synced to the database and viewers.

Summary of Changes:
------------------

1. public/index.html
   - Added a "Clear" button to the editor-header-actions under the owner view section:
     <button class="btn-copy-editor" id="btn-clear-owner" title="Clear Content">
       <i class="fa-solid fa-eraser"></i> Clear
     </button>

2. public/style.css
   - Added styling for the `.toast-action-btn` to match the neo-brutalist aesthetic (pastel purple background, black outline, and offset shadow).

3. public/js/utils/toast.js
   - Extended `showToast` to accept custom options including a callback action (`action.text` and `action.onClick`), customizable toast `duration`, and an `onExpire` callback.
   - Added a `dismiss()` return function to allow programmatic removal of active toasts.

4. public/js/components/Editor.js
   - Constructor: Initialized state tracking variables (`this.preClearContent`, `this.clearSaveTimeout`, `this.clearToast`) to handle the undo flow. Bound the clear button (`btnClear`) DOM element.
   - bindEvents(): Registered clear button event listener to check if the editor is already empty. If empty, displays a warning toast. Otherwise, invokes the `clearContent()` method.
   - Added clearContent() method:
     - Backs up current content to `this.preClearContent`.
     - Clears the editor text area UI immediately and updates line numbers.
     - Starts an 8-second timer (`this.clearSaveTimeout`) to trigger saving the empty state.
     - Displays the undo toast. Clicking the "Undo" button restores the backup content, cancels the timeout, and resets the status without making a network request.
   - Updated triggerSave(): Modified to immediately cancel any pending clear operation, cancel the undo timer, and dismiss the toast if the user starts typing inside the editor.
   - Updated destroy() method:
     - Clears timers and toast instances.
     - If the user navigates away or closes the tab while the Undo toast is pending, commits/saves the clear state immediately to the database.
