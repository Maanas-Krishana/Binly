# Git Workflow Rule

## ⚠️ NEVER COMMIT DIRECTLY TO MAIN

1. **Active Branch**: ALWAYS keep the working branch set to `features-and-improvements`.
2. **Commits & Pushes**: All commits and pushes MUST be made to `features-and-improvements` branch.
3. **Main Branch Protection**: NEVER commit or push directly to `main`. `main` is strictly updated via Pull Requests or explicit user instruction.
